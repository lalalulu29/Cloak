# Cloak — Product Vision

## 1. Общая идея
Cloak — iOS-приложение для тренировки рабочей памяти через ежедневный ритуал:
- утром пользователь получает число;
- днем получает напоминания «Помнишь число?»;
- вечером вводит число по памяти;
- приложение сохраняет результат и показывает прогресс.

Идея основана на бытовом сценарии запоминания номера (например, гардероба), поэтому упражнение остается простым и практичным.

## 2. Ценность для пользователя
- Короткая ежедневная тренировка (1–2 минуты).
- Измеримый прогресс: история, серия, точность.
- Формирование привычки удерживать информацию в памяти в течение дня.

## 3. Принципы MVP
- Только режим «Числа».
- Локальное хранение и работа без сети.
- Честная механика: число показывается утром один раз и не раскрывается повторно в течение дня.
- Вечерний ввод доступен только после времени вечерней проверки.

## 4. Текущий цикл дня (реализовано)
1. Утренний показ числа (один раз).
2. Дневные локальные напоминания без раскрытия ответа.
3. Вечерняя проверка (ввод открывается только после времени окончания дня).
4. Сохранение результата (`correct` / `wrong` / `missed`) в историю.

## 5. Управление сложностью
- Частота дневных напоминаний: 1...5 раз в день.
- Семантика частоты:
  - 1 раз = сложнее;
  - 5 раз = проще.
- Настройка длины числа: 3...8 (по умолчанию 4).
- Новая длина применяется к ближайшему не начатому периоду.

## 6. Первый запуск (реализовано)
На первом запуске пользователь задает:
- начало дня;
- конец дня;
- частоту дневных напоминаний (через уровни «Просто / Средне / Сложно / Очень сложно»).

После этого сразу запрашивается разрешение на уведомления.

## 7. Что оставить на после-MVP
- Режим «Слова» (слово + перевод).
- Смешанный режим.
- Расширенная аналитика.
- Синхронизация между устройствами.
- Виджеты.

## 8. Монетизация (рабочая гипотеза)
Рекомендуемый старт: freemium.
- Бесплатно: полный базовый цикл и базовая статистика.
- Pro: расширенная аналитика, дополнительные режимы, синхронизация.

## 9. Риски и нюансы
- Слишком частые напоминания могут раздражать пользователя.
- Важно корректно обрабатывать пропуски дней.
- Требуется аккуратная обработка даты/полуночи/часовых поясов.
