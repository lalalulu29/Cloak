# Cloak — PRD Checklist (MVP)

## 1. Product Goal
Собрать рабочий MVP ежедневной тренировки памяти:
- утром показать число;
- днем поддерживать удержание через напоминания;
- вечером проверить ввод;
- сохранить результат и прогресс.

## 2. Functional Requirements
## FR-1 Daily number generation
- Одно число на локальный день.
- В течение дня число стабильно.

Status: `Done`

## FR-2 Morning reveal
- Показ числа утром на отдельном экране.
- После подтверждения повторный показ в этот день недоступен.

Status: `Done`

## FR-3 Daytime reminders
- Дневные напоминания «Помнишь число?».
- Частота настраивается пользователем.

Current behavior:
- диапазон `1...5` (без `0`);
- 1 = сложнее, 5 = проще.

Status: `Done`

## FR-4 Evening answer
- Ввод числа и проверка вечером.
- Результаты: `correct` или `wrong`.

Current behavior:
- поле ввода и кнопка не показываются до времени вечерней проверки.

Status: `Done`

## FR-5 Missed day handling
- Отсутствие ответа до следующего дня приводит к статусу `missed`.

Status: `Done`

## FR-6 History and stats
- История с датой и результатом.
- Базовые метрики: серия, лучшая серия, точность, число ответов.

Status: `Done`

## FR-7 Settings
- Время начала/конца дня.
- Количество дневных напоминаний.
- Напоминание за N минут до полуночи.
- Длина числа.
- Статус уведомлений.

Status: `Done`

## FR-8 First-launch setup
- На первом запуске пользователь задает начало дня, конец дня и частоту напоминаний.
- Разрешение уведомлений запрашивается сразу в первом запуске.

Status: `Done`

## FR-9 Number length management
- Настройка длины числа (по умолчанию `4`, диапазон `3...8`).
- Изменение применяется к ближайшему не начатому периоду.

Status: `Done`

## 3. Non-Functional Requirements
- Локальное хранение данных.
- Работа без сети.
- Понятный UX.

Status: `Done`

## 4. Open QA / Risks
- Смена часового пояса.
- Переход через полночь при открытом приложении.
- Системные сценарии с отключенными уведомлениями.

Status: `In progress`
